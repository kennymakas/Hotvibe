🔥 HotVibe
HotVibe is a modern, responsive social media web application built for sharing content, discovering new posts, and connecting through comments and conversations.

The project focuses on providing a clean, engaging, and mobile-friendly social experience across desktop, tablet, and mobile devices.

✨ Features
📱 Fully responsive design
📝 Create and share posts
🎥 Media-focused content
💬 Comments and conversations
❤️ Social interactions
🔥 Trending and engaging content
👤 User-focused social experience
⚡ Fast Vite-powered frontend
🌐 Node.js server
📐 Responsive layouts for different screen sizes
🛠️ Tech Stack
Frontend: React
Build Tool: Vite
Backend/Server: Node.js
Styling: CSS
Package Manager: npm
Development Environment: JavaScript / JSX

📱 Responsive Design
HotVibe is designed to provide a consistent experience across:

📱 Mobile phones
📲 Tablets
💻 Laptops
🖥️ Desktop computers
The interface adapts to different screen sizes while keeping content, media, and conversations easy to access.

💬 Community
HotVibe is designed around interaction and community. Users can discover content, share their own posts, and participate in conversations through comments and social engagement.

🔒 Security
Before deploying HotVibe publicly, review environment variables, authentication, API endpoints, user-generated content handling, and server configuration.

The current project dependencies have been audited with:

npm audit
